# airake

Application facade reexporting airake-core, airake-chat and airake-openrouter. Includes rake-image, rake-video and rake-tts, using OPENROUTER_API_KEY. PostgreSQL, direct OpenAI and Jev are opt-in packages.

See the [workspace documentation](https://github.com/tommyengstrom/ai-rake#readme) for usage and migration notes.
