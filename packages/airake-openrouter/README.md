# airake-openrouter

OpenRouter chat, images, speech and asynchronous video jobs. Each modality has a model class, typed model records and a Custom model accepting an Aeson.Object. Client credentials/routing/logging live in `Rake.Providers.OpenRouter.Settings`. Depends on airake-core, not the chat frontend.

See the [workspace documentation](https://github.com/tommyengstrom/ai-rake#readme) for usage and migration notes.
